# NEVIX — BUILD • AUTOMATE • GROW

Official digital platform for **NEVIX**, a digital technology, marketing, and AI automation agency in **Ahmedabad, Gujarat, India**.

## Core Pillars
- **BUILD**: Website Development, E-commerce Development, Website Redesign, CRM Development, ERP Development, SaaS & Custom Software Development.
- **AUTOMATE**: AI Chatbots, Autonomous AI Agents, WhatsApp Automation, Workflow & Lead Automation.
- **GROW**: Technical SEO, Local SEO, Google Business Profile Optimization, Digital Marketing, Google Ads, Social Media Marketing.

## Tech Stack
- **React 19** + **Vite 6**
- **Three.js** / **React Three Fiber** / **Drei** (3D NEVIX Digital Core)
- **GSAP** + **ScrollTrigger** (Kinetic Typography, Horizontal Scroll, Scroll-Driven Reveals)
- **Lenis** (Smooth Scrolling)
- **Tailwind CSS v4**
